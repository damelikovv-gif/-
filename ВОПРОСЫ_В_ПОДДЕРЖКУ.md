---

## 🎯 СРОЧНО спросите у поддержки:

### 1. **Куда именно загружать фид?**
- В какой раздел: "Товары и услуги", "Каталог", "Прайс-лист"?
- Может быть есть специальный раздел для услуг?

### 2. **Какие обязательные поля для услуг?**
Попросите список обязательных и рекомендуемых полей:
- `<name>` — название
- `<price>` — цена
- `<description>` — описание
- `<categoryId>` — категория
- Что еще ОБЯЗАТЕЛЬНО?

### 3. **Валюта: RUB или RUR?**
- Какой код валюты нужен: `RUB` или `RUR`?
- У меня есть версии с обоими вариантами

### 4. **Нужны ли дополнительные поля для услуг?**
- `<picture>` — изображение (обязательно или нет?)
- `<vendor>` — поставщик
- `<param>` — параметры услуги
- `<sales_notes>` — примечания
- Другие специфичные поля?

### 5. **Есть ли пример YML-файла для услуг?**
- Может ли поддержка прислать образец файла?
- Или ссылку на документацию по формату для услуг?

### 6. **Атрибут type="service"**
- Нужно ли указывать `type="service"` в теге `<offer>`?
- Или услуги загружаются как обычные товары?

### 7. **URL файла**
- Может ли быть проблема с GitHub (raw.githubusercontent.com)?
- Нужен ли файл на другом хостинге?
- Или лучше загрузить файл напрямую (если есть такая опция)?

## 💡 Возможные причины ошибки

Пока вы уточняете, я предполагаю что может быть не так:

### Причина 1: Нужен DOCTYPE другого типа
Может требоваться другая декларация документа

### Причина 2: Отсутствует обязательное поле
Возможно для услуг ОБЯЗАТЕЛЬНО нужно поле `<picture>` (изображение)

### Причина 3: Неправильный type
Может быть нужен специальный тип офферов для услуг

### Причина 4: GitHub заблокирован
Яндекс может не принимать файлы с raw.githubusercontent.com

### Причина 5: Проблема с кодировкой
Хотя у нас UTF-8, может быть какие-то специфичные символы
