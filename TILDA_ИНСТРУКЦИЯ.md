# Как загрузить YML-фид на Tilda

## Способ 1: Через файловый менеджер Tilda (РЕКОМЕНДУЕТСЯ)

### Шаг 1: Переименуйте файл
Tilda может не распознать расширение `.xml` правильно, поэтому переименуйте:
- `yandex_business_feed.xml` → `yandex_business_feed.txt`

### Шаг 2: Загрузите файл в Tilda
1. Войдите в ваш проект на https://tilda.cc/
2. Откройте **"Настройки сайта"** (иконка шестеренки)
3. Перейдите в раздел **"Файлы"** или **"File Manager"**
4. Нажмите **"Загрузить файл"** или **"Upload file"**
5. Выберите файл `yandex_business_feed.txt`
6. Дождитесь загрузки

### Шаг 3: Получите ссылку на файл
После загрузки Tilda покажет URL файла, например:
```
https://static.tildacdn.com/tild3333-3333-4444-b111-111111111111/yandex_business_feed.txt
```

### Шаг 4: Используйте эту ссылку в Яндекс Бизнес
Просто вставьте полученную ссылку в настройках импорта Яндекс Бизнес.

⚠️ **ВАЖНО**: Яндекс Бизнес должен принять файл с расширением `.txt` — в нём всё равно XML-разметка.

---

## Способ 2: Через GitHub (если Способ 1 не работает)

Если Яндекс требует именно `.xml` расширение, используйте ваш GitHub:

### Получите прямую ссылку из вашего репозитория:

1. Перейдите в ваш репозиторий на GitHub
2. Откройте файл `yandex_business_feed.xml`
3. Нажмите кнопку **"Raw"** (справа вверху)
4. Скопируйте URL из адресной строки, например:
```
https://raw.githubusercontent.com/ваш-username/ваш-репозиторий/main/yandex_business_feed.xml
```

5. Используйте этот URL в Яндекс Бизнес

⚠️ **Минус**: При каждом обновлении фида нужно будет коммитить изменения в GitHub.

✅ **Плюс**: Настоящий `.xml` файл, который точно примет Яндекс.

## Способ 3: Через облачное хранилище (альтернатива)

### Google Drive:
1. Загрузите файл в Google Drive
2. Откройте доступ по ссылке (Правая кнопка → "Открыть доступ" → "Все, у кого есть ссылка")
3. Скопируйте ID файла из ссылки (между `/d/` и `/view`)
4. Создайте прямую ссылку:
```
https://drive.google.com/uc?export=download&id=ВАШ_ID_ФАЙЛА
```

### Dropbox:
1. Загрузите файл в Dropbox
2. Создайте публичную ссылку
3. Замените `www.dropbox.com` на `dl.dropboxusercontent.com`
4. Замените `?dl=0` на `?dl=1`

## Способ 4: Использовать поддомен для API (для продвинутых)

Если у вас есть доступ к настройкам DNS вашего домена:

1. Создайте поддомен `feeds.krismass.ru`
2. Настройте его на GitHub Pages или другой бесплатный хостинг
3. Разместите там YML-фид
4. Используйте красивый URL: `https://feeds.krismass.ru/yandex_business_feed.xml`

## 🎯 Рекомендация для вас:

### Вариант A (самый простой):
1. Загрузите `yandex_business_feed.xml` как `.txt` в Tilda
2. Используйте полученный URL в Яндекс Бизнес
3. Если Яндекс не примет `.txt` — переходите к Варианту B

### Вариант B (надежный):
1. Используйте прямую ссылку из GitHub:
```
https://raw.githubusercontent.com/YOUR-USERNAME/YOUR-REPO/cursor/generate-yml-feed-for-yandex-business-69c6/yandex_business_feed.xml
```
2. Замените `YOUR-USERNAME` и `YOUR-REPO` на реальные значения
3. Используйте эту ссылку в Яндекс Бизнес

## Проверка доступности фида

После загрузки проверьте, что файл доступен:

1. Откройте полученный URL в браузере
2. Вы должны увидеть XML-код вашего фида
3. Если видите — значит всё работает!

---

## Обновление фида

### Для Tilda:
- Загрузите новый файл с тем же именем (старый перезапишется)

### Для GitHub:
- Закоммитьте изменения в репозиторий
- Фид обновится автоматически

---

## Частые проблемы

### "Файл недоступен"
- Проверьте, что файл загружен и опубликован
- Убедитесь, что сайт на Tilda опубликован

### "Неверный формат"
- Проверьте, что в файле сохранилась XML-разметка
- Откройте файл в браузере и убедитесь, что видите XML

### "CORS ошибка"
- Используйте прямую ссылку из Tilda
- Не используйте сокращенные или редирект-ссылки
