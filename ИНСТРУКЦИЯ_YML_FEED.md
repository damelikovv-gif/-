# Инструкция по использованию YML фида для Яндекс Бизнес

## Описание

Созданы два варианта YML-фида для загрузки услуг массажа KM STUDIO в рекламный кабинет Яндекс Бизнес:

1. **`yandex_business_feed.xml`** — упрощенная версия (РЕКОМЕНДУЕТСЯ)
2. **`yandex_business_feed.yml`** — расширенная версия с дополнительными полями

⚠️ **ВАЖНО**: Используйте файл с расширением `.xml` — он гарантированно загрузится в Яндекс Бизнес.

## Что было добавлено в новый фид

### 1. **Дополнительные поля компании**
- `<phone>` — телефон компании (замените `+7 (XXX) XXX-XX-XX` на реальный номер)
- `<email>` — email для связи (обновите при необходимости)

### 2. **Расширенная структура категорий**
Созданы подкатегории для лучшей организации услуг:
- Массажи (основная категория)
  - Расслабляющие массажи
  - Лечебные массажи
  - Косметические массажи

### 3. **Дополнительные поля для каждого предложения**

#### Обязательные поля для Яндекс Бизнес:
- `type="service"` — тип предложения (услуга)
- `<picture>` — URL изображения услуги
- `<delivery>false</delivery>` — доставка не требуется
- `<pickup>true</pickup>` — услуга оказывается в офисе
- `<store>true</store>` — доступно в студии

#### Рекомендуемые поля:
- `<vendor>` — название бренда
- `<vendorCode>` — артикул услуги (для учёта)
- `<oldprice>` — старая цена (где применимо, для показа скидки)
- `<sales_notes>` — дополнительная информация о покупке
- `<manufacturer_warranty>` — гарантия
- `<country_of_origin>` — страна происхождения

#### Параметры услуг:
- `<param name="Длительность">` — длительность процедуры
- `<param name="Филиал">` — название филиала
- `<param name="Тип массажа">` — тип массажа
- `<param name="Эффект">` — ожидаемый эффект
- `<param name="Зона воздействия">` — зона применения
- `<param name="Особенность">` — особенности процедуры

## Что нужно сделать перед загрузкой

### 1. **Обновить контактную информацию**
В файле `yandex_business_feed.yml` замените:
```xml
<phone>+7 (XXX) XXX-XX-XX</phone>
<email>info@krismass.ru</email>
```

### 2. **Добавить реальные URL изображений**
Замените заглушки на реальные URL изображений:
```xml
<picture>https://krismass.ru/images/services/relax-massage.jpg</picture>
```

Требования к изображениям:
- Формат: JPG, PNG
- Размер: минимум 300×300 px, рекомендуется 600×600 px или больше
- Качество: высокое, без водяных знаков
- Содержание: должно соответствовать услуге

### 3. **Проверить цены и наличие**
Убедитесь, что все цены актуальны и параметр `available="true"` соответствует действительности.

### 4. **Проверить UTM-метки**
В URL всех предложений добавлены UTM-метки для отслеживания:
```
utm_source=yandex_business
utm_medium=import
utm_campaign=products
utm_branch=yunost (или vesennyaya)
utm_service=название_услуги
```

## Как загрузить фид в Яндекс Бизнес

### Шаг 1: Размещение файла
1. Загрузите файл `yandex_business_feed.yml` на ваш сервер
2. Убедитесь, что файл доступен по прямой ссылке (например: `https://krismass.ru/feeds/yandex_business_feed.yml`)
3. Файл должен быть доступен для скачивания без авторизации

### Шаг 2: Настройка в Яндекс Бизнес
1. Войдите в **Рекламный кабинет Яндекс Бизнес**: https://business.yandex.ru/
2. Перейдите в раздел **"Товары и услуги"**
3. Нажмите **"Добавить каталог"** или **"Импорт"**
4. Выберите **"YML-файл"**
5. Введите URL вашего фида: `https://krismass.ru/feeds/yandex_business_feed.yml`
6. Нажмите **"Загрузить"**

### Шаг 3: Проверка фида
1. Яндекс автоматически проверит фид на ошибки
2. Просмотрите отчёт о загрузке
3. Исправьте ошибки, если они есть
4. Повторите загрузку

### Шаг 4: Настройка автообновления
1. Яндекс Бизнес будет автоматически проверять ваш фид (обычно раз в сутки)
2. При изменении цен или услуг просто обновите файл на сервере
3. Изменения подтянутся автоматически при следующей проверке

## Валидация фида

Перед загрузкой рекомендуется проверить фид на ошибки:

### Онлайн-валидаторы:
1. **Яндекс.Вебмастер** — https://webmaster.yandex.ru/tools/market-feed/
2. **FeedValidator** — специализированные сервисы для проверки YML

### Типичные ошибки:
- Неэкранированные символы `&`, `<`, `>` в тексте (используйте `&amp;`, `&lt;`, `&gt;`)
- Отсутствие обязательных полей
- Неправильный формат URL
- Недоступные изображения

Предложения с качественными фото получают на 30-40% больше кликов.

В описаниях используйте слова, которые ищут клиенты: "массаж", "релакс", "спина", "антицеллюлитный" и т.д.

### 5. **Отслеживайте статистику**
Используйте UTM-метки в Яндекс.Метрике для анализа эффективности рекламы.

## Возможные причины ошибок загрузки

Если фид не загружается, проверьте:

1. **Расширение файла** — используйте `.xml` вместо `.yml`
2. **Кодировка** — файл должен быть в UTF-8
3. **Доступность по URL** — файл должен быть доступен без авторизации
4. **Размер описаний** — не более 3000 символов
5. **Корректность URL** — все ссылки должны быть рабочими
6. **Изображения** — если добавляете `<picture>`, URL должны быть доступны
